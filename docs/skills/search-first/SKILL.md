# 先搜再写（Search Before You Write）

像个老程序员一样：动手写新代码前，先确认项目里有没有已经写好的、能直接复用的东西。

## 第一步：先想清楚要什么

用一两句话说清这次要解决的问题，别急着写代码

## 第二步：先搜，再写

写任何新代码之前，按顺序搜索有没有现成方案：

1. 项目自己的代码库——按类名、方法名、功能关键词、常见命名搜
2. 项目里已安装的工具、库、技能包
3. 常用依赖仓库里的现成库

## 第三步：给出判定结论

搜索完必须明确写一行结论，选一个：

- **采用**：已有代码能精确满足，直接复用
- **扩展**：已有代码大部分匹配，在它基础上包一层/加一点
- **组合**：把两三个现成的小组件拼起来用
- **新建**：确实没有现成的，才动手写，但注明"我搜过了"

## 第四步：复用要带上下文

复用时先读一下那段代码的注释和调用方，确认它确实是你要用的那个，别想当然

## 记住

- 已有的代码、工具类、基础组件是项目的一部分，先认识它们再写代码
- 写之前花几秒钟搜索，省的是之后几小时的重复劳动
- 你不是从零开始，是站在这个项目已有的基础上继续盖楼
- 就算最后决定新建，也说明一下你搜过、为什么没有可复用的
